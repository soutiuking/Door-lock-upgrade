# ESP-01S AP Wi-Fi 门锁改造（v0.1）

> **版本阶段：0.x 内测版 · 第 1 版**
>
>这是“霁泽入微”开源项目，也是从学习到正式的工程转别的思路，本项目是个人制作的实验性门锁改造方案，尚未经过安全认证或长期可靠性验证。请勿将它作为唯一的出入方式，也不要直接用于需要生命安全、消防疏散或高安全等级的场所。

## 项目缘起

起因是某学校宿舍的学生出门时懒得带钥匙，有人一着急、发了脾气，之后便动手改造门锁，就开始动手做一个不用随身带传统钥匙也能操作的方案。

这是一次从真实小麻烦出发的个人软硬件改造。为保护当事人隐私，不公开学校、宿舍及个人身份信息。网页界面由 Mimo 大模型辅助生成；硬件设计和固件软件由项目作者个人所有，并在本仓库按开源协议公开。

## 仓库内容

- `arduino-esp01s-esp01s-ap-wifi-io0/esp01s_ap_lock/`：ESP-01S 固件、配置存储和嵌入式网页界面。
- `ProPrj_门锁升级_2026-10-03.epro2`：电路/硬件设计工程文件（EPro 项目格式）。打开和继续编辑需要兼容的 EPro CAD 软件。

## 功能概览

- ESP8266/ESP-01S 建立本地 Wi-Fi SoftAP，并提供内置网页操作界面。
- 网页可进行开锁操作及管理员配置；舵机动作参数和运行状态由固件管理。
- 支持 Wi-Fi 定时/省电逻辑、时间同步和配置持久化（具体行为以当前固件实现为准）。
- 网页界面由 Mimo 大模型辅助生成，并嵌入固件，不需要单独部署网页服务器。

## 硬件与接线提示

本版本面向 ESP-01S 与舵机改造，**请先阅读并核对 EPro 电路工程及板卡引脚定义，再接线**。固件当前定义 IO0 为舵机电源开关控制信号（应通过合适的 MOSFET/驱动电路，不可直接给舵机供电，该项目使用了双mos管控制电源给舵机进行供电），IO1/TXD0 为舵机 PWM 信号。ESP-01S 启动时 IO0 必须满足启动电平要求；舵机应使用满足电流需求的独立电源，并与控制电路共地。不要仅凭网页描述代替电路核验。

## 固件编译与烧录

1. 安装 Arduino IDE 和 ESP8266 Arduino Core，选择与实际板卡相符的 ESP-01S/ESP8266 配置。
2. 打开 `arduino-esp01s-esp01s-ap-wifi-io0/esp01s_ap_lock/esp01s_ap_lock.ino` 所在目录下的草图。
3. 核对板型、Flash 参数、引脚接线和舵机机械行程后编译并烧录。
4. 固件默认 SoftAP 密码为 `88888888`，管理员密钥初始值为 `888888`。首次使用请立即更改；不要在不可信环境保留默认凭据。
5. 当前源码定义 `DEBUG_MODE` 为 `1`（调试模式）。部署前请自行评估并调整，且验证 Wi-Fi 行为与门锁机构安全状态。

当前发行状态为内测第一版，不保证不同 Arduino Core/板卡配置均可直接编译或稳定运行。提交问题时请附上板卡型号、Core 版本、接线方式和完整编译/运行日志；请勿上传真实密码、管理员密钥或可识别个人身份的信息。

## 安全与使用须知

- 这是实验性门锁控制项目，不是经过认证的防盗或生命安全产品。网络口令、认证方式、机械强度和断电行为均需由使用者自行评估。
- 断电、舵机卡死、网络中断或固件异常时，门锁可能无法按预期动作。保留可从内侧安全离开的方式和可靠的备用开门方案，确保不阻碍消防疏散。
- 实际使用是使用舵机的机械行程，确保门锁正常打开和关闭，不去更改原有锁的机构，知识使用舵机模拟人在门后拨动锁的机构。
- 先在脱离真实门锁的台架上测试，再进行机械安装；确认舵机不会过行程、夹伤人员或损坏门锁。未经许可不要改造他人或公共设施。
- 使用者须遵守所在地法律、学校/物业规定，并取得门锁所有者许可。作者不对安装、使用、改造或故障造成的损失承担保证责任；详见 `LICENSE`。
