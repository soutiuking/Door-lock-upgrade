# v0.2：STM8L051F3 敲门唤醒 + ESP-01S 门锁

> **当前默认烧录行为：PC4 恒高排查测试。** main.c 中 `FORCE_PC4_HIGH_TEST=1` 已开启。初始化时先把 PC4 输出锁存置高，再启用推挽输出；之后持续 RUN，不执行 HALT/WFI，不读取 PB0/PC1、不计时断电、不启用中断或定时器。正常敲门逻辑暂时旁路。
>
> 重新编译、烧录后同时测 PC4、STM8 VDD 和下游电源轨。如果 PC4 稳定高而下游电源仍断续，重点检查电源驱动、稳压和负载；若 STM8 VDD/NRST 异常，检查电源跌落或复位。复位期间引脚由硬件默认状态决定，软件不能保证复位期间也保持高。
>
> 排查完成后将 `FORCE_PC4_HIGH_TEST` 改为 `0` 并重新编译烧录，即恢复下文的上电等待50ms单次模式选择及三次敲门逻辑。ESP8266 核心逻辑不变，其 GPIO0 仍独立控制舵机电源。


STM8 控制 Wi-Fi 和开锁机构的总供电。三次敲门只使 PC4 拉高、开启供电；实际开锁继续由原来的 ESP8266 网页密码认证及舵机状态机完成。

## 原理结构与供电修正

见 [系统原理结构图、状态图与供电排查](docs/architecture.md)。PC4 为推挽静态输出，上电先保持低并等待 50 ms，然后仅采样一次 PB0，锁定模式到下次复位。运行期间不读取 PB0，不启用 PB0 中断。测试模式关闭 TIM4，进入 HALT 并保持 PC4 高。

## 引脚

| STM8 引脚 | TSSOP20 脚号 | 用途 |
| --- | --- | --- |
| PC1 | 19 | 震动数字信号，低电平空闲，上升沿触发 |
| PC4 | 20 | 总电源开关控制，高电平供电 |
| PB0 | 10 | 高：测试常供电；低：使用模式 |
| PA0 / SWIM | 3 | 保留下载、调试功能 |
| PA1 / NRST | 4 | 保留复位功能 |

PB0 配置为浮空输入，必须由板上开关、跳线或外部电阻提供明确高/低电平，不可悬空。PC1 也依赖传感器给出明确的空闲低电平。PC4 接电源开关驱动电路。

## 敲门规则

1. 使用模式上电后 PC4 为低，STM8 进入 **HALT 停机模式**。上电时已有的静态高电平不直接算作一次敲门。
2. PC1 上升沿唤醒 STM8，首次敲门计为第 1 次，开始固定 10 秒窗口。
3. 每次有效敲门后至少间隔 **1000 ms**；期间屏蔽 PC1 中断，反复高电平不计数，也不推迟下一次允许计数的时刻。
4. 重新使能检测还要求 PC1 经 1 ms 采样确认连续低电平 **30 ms**。持续高电平只计一次。低电平确认期间的短脉冲可能无法被采样捕获，效果需用实际传感器波形确认。
5. 第三次有效上升沿距首次不超过 **10000 ms**，PC4 拉高 **60000 ms**。供电期间屏蔽震动，不重新计数，不延长供电。
6. 超过 10 秒仍不足三次，或 60 秒供电结束后，PC4 拉低、计数清零，关闭 TIM4 并重新进入 HALT，等待下一次上升沿。

例如：0、1、2 秒有效；0、5、10 秒有效；0、0.5、1 秒仅计两次；0、9、10.001 秒不能组成一次有效开门信号。时间为 HSI 标称值，实际误差受芯片 RC 时钟精度影响。

这里只做上升沿计数、1 秒屏蔽及低电平稳定确认，不额外要求高脉冲保持固定时间。软件消抖不能给模拟输入增加电压滞回；若传感器持续振荡且满足上述间隔和低电平时间，仍可能被视为三次敲门。

PB0 在上电等待 50 ms 后只读取一次：高为工程/测试常供电，低为使用模式。采样后修改或拔动杜邦线不会改变模式，必须复位或重新上电才重新选择。这里是等待电源稳定后单次采样，不是连续检测 50 ms 的电平。

## 低功耗

- HSI 16 MHz 除以 8，系统主频 **2 MHz**。
- 上电等待 50 ms、敲门计数和使用模式供电期间仅使能 TIM4，分频 16、ARR=124，产生 1 ms 节拍；CPU 在中断之间执行 WFI。
- 等待敲门及测试常供电时，停止 TIM4 并关闭其时钟，执行 HALT；不启用 RTC 或周期唤醒。PB0 已锁定且中断关闭，不再唤醒 MCU。
- 不启用 ADC、SPI、I2C、UART、DMA、BEEP、其他定时器、PVD、外部晶振和 LSI，关闭其他外设时钟，HALT 使用 ULP 配置。
- PA0/SWIM、PA1/NRST 保持复位配置。未使用的 PA2/3、PB1–7、PC5/6、PD0 配置上拉输入；**PC0 无内部上拉，配置为真开漏输出低电平**。这些引脚应未连接其他功能；若有额外接线，应调整初始化掩码。
- 未启动看门狗。烧录时应使用软件启动看门狗的选项字节配置；若启用硬件看门狗，需要另行设计喂狗/停机策略。
- 测待机电流时断开调试器，测量实际总电流；本版没有实测功耗数值。

## STM8 编译和烧录

源码沿用已有工程的 **STVD + Cosmic STM8 C** 语法，不依赖 ST 标准外设库。

直接在 STVD 中选择 **File → Open Workspace**，打开 [doorup.stw](doorup.stw)。工作区引用 [doorup.stp](doorup.stp)，已配置 STM8L051F3、STM8 Cosmic、Debug/Release、两份 C 源码和两份头文件；无需新建工程或重复添加向量表。

工具链路径预设为本机 `E:\stm8l-tools\cosmic\CXSTM8`，头文件目录为 Hstm8、库目录为 Lib。换电脑时在 Project Settings → General 中修改工具链路径，并同步检查 C Compiler 的 -i 头文件路径、Linker 的 -l 库路径（本工程为兼容旧版 STVD，显式保存了这两项路径）。所有项目源码引用为相对路径，可整体复制 v0.2 目录。

选择 Debug 或 Release 后执行 Build（F7）。编译使用 +mods0，Debug 增加 +debug -pxp -no -l；链接使用已保存的自定义 doorup.lkf，关闭自动重生成，避免覆盖已有内存布局。Post-Build 已配置 cvdwarf 转换 ELF，然后 chex 生成 S19。Debug 目录保存调试 ELF，烧录使用对应目录的 doorup.s19。

也提供同参数的命令行构建，在仓库根目录执行：

```powershell
./versions/v0.2/build_cosmic.ps1 -Configuration Debug
./versions/v0.2/build_cosmic.ps1 -Configuration Release
# 工具链不在默认位置时，加 -Toolchain '实际的CXSTM8目录'
```

现有 `Debug/doorup.lkf`、`Release/doorup.lkf` 保留：Flash 0x8000–0x9FFF，向量表占前 0x80 字节；数据区使用 RAM 低 512 字节，栈顶为 0x03FF。状态机以静态函数编译进 main.o，无需增加独立目标文件。启用中断为 EXTI1=IRQ9、TIM4=IRQ25；PB0 中断关闭，IRQ8 使用默认处理函数。

2026-10-18：已在本机发现并使用 Cosmic 工具链，当前 PC4 恒高测试固件已完成 Debug、Release 实际编译、链接、ELF 转换及 S19 生成。已在 STVD 4.3.12 中打开工作区并分别执行 Debug、Release 构建，两者均为 0 错误、0 警告。实板供电波形及复位情况仍需烧录后验证；主机模拟测试不能替代电气测量。

## ESP8266

打开 `arduino-esp01s-esp01s-ap-wifi-io0/esp01s_ap_lock/esp01s_ap_lock.ino`。已在 **ESP8266 Arduino Core 3.1.1、generic ESP8266** 配置下编译通过。

上电初始化后立即启动 AP；删除每 5 分钟开启 1 分钟、常开时段及软件调试模式对 Wi-Fi 的控制。网页去掉相关设置，保留上行网络和时间同步。ESP8266 不知道 PC4 剩余供电时间；`wifiNext=0` 表示没有软件 Wi-Fi 切换计划。

保持 IO0 舵机供电控制、IO2 PWM、密码认证、管理员功能、舵机动作参数和 Flash 存储算法。`LockConfig` 中旧的 `winStart`、`winEnd`、`debugMode` 字段保留以兼容存储布局，已不参与 Wi-Fi 控制，也不代表 STM8 的 PB0 状态。

**60 秒到时直接断电**，包括网页正在操作或舵机正在动作的情况。较长调试可使用 PB0 高电平模式。

| 台架操作 | 应观察到的结果 |
| --- | --- |
| PB0=0，上电，无震动 | 先等待50ms，再锁定使用模式；PC4=0，定时器停，进入 HALT |
| 第一次上升沿 | 从 HALT 唤醒，PC4 仍为 0 |
| 0、1、2 秒输入脉冲 | 第三次后 PC4=1，约 60 秒后回到 0 |
| 单次敲门后 1 秒内反复跳变 | 不增加有效计数 |
| 少于三次且超过 10 秒 | PC4 保持 0，重新进入 HALT |
| PC1 持续高电平 | 不重复计数，超时可进入 HALT |
| 第三次在 10 秒 / 超过 10 秒 | 前者成功，后者不属于前一轮 |
| 供电期间继续敲门 | 不延长 60 秒窗口 |
| 模式采样后改变 PB0 | 保持原有模式；复位等待50ms后才重新读取 |
| SWIM 下载、示波器观察 | 可连接调试，核验 HALT 唤醒、PC4 时序及实际电流 |

管脚、寄存器与中断依据 [DS9178 数据手册](https://www.st.com/resource/en/datasheet/stm8l051f3.pdf)，睡眠指令依据 [PM0044 编程手册](https://www.st.com/resource/en/programming_manual/pm0044-stm8-cpu-programming-manual-stmicroelectronics.pdf)。
